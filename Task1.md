Выбрать существующее веб-приложение, которое будете тестировать. И создать репозиторий в котором будут размещаться файлы заданий:

В README.md:

краткое описание сайта
указать ФИО, Группу и логины GitHub участников
Описать в техническом задании:

Цель и задачи сайта
Целевая аудитория сайта
Проблему (проблемы), которые решает приложение
Аналоги и сравнение с ними
описание работы приложения (тип проекта: веб, десктоп, мобильное и т.п.)
Задачи на этот спринт:

Создать репозиторий в GitHub
Создать Milestone - Постановка задачи
оформить README.md (краткое описание проекта и состав команды)
Техническое задание.md (указать на него ссылку в README.md) - в нем описать проект и планируемые задачи
Логин преподавателя в GitHub: Laggon

В ответе прикреплять ссылку на Pull request с добавлением файлов Технического задания и общего описания проекта. Также должны быть заполнены задачи в Issues.

* - если более крупный проект

Не нужно выполнять Merge до Review с Approve (одобрением) преподавателя!

Прикреплять ссылки на PR после Approve преподавателя и Merge в основную ветку.
