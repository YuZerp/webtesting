# Тестирование веб-приложения Songsterr

## Краткое описание проекта
**Songsterr** — это веб-приложение и мобильная платформа, представляющая собой архив гитарных, басовых и барабанных табулатур (табов) [citation:1]. Ключевая особенность сервиса — интерактивный проигрыватель с реалистичным звучанием, позволяющий музыкантам не только просматривать аппликатуры, но и прослушивать их, изменять темп, зацикливать сложные фрагменты и изолировать отдельные партии инструментов [citation:1][citation:4]. Платформа легальна и выплачивает роялти правообладателям [citation:1].
