# Тестирование веб-приложения Songsterr

## Краткое описание проекта
**Songsterr** — это веб-приложение и мобильная платформа, представляющая собой архив гитарных, басовых и барабанных табулатур (табов). Ключевая особенность сервиса — интерактивный проигрыватель с реалистичным звучанием, позволяющий музыкантам не только просматривать аппликатуры, но и прослушивать их, изменять темп, зацикливать сложные фрагменты и изолировать отдельные партии инструментов. Платформа легальна и выплачивает роялти правообладателям.
