# Техническое задание (ТЗ) на тестирование веб-приложения Songsterr

## 1. Цель и задачи сайта
**Цель:** Предоставить музыкантам удобный и легальный инструмент для разучивания музыкальных произведений на гитаре, басу и ударных с помощью интерактивных табулатур.

**Задачи:**
- Предоставить доступ к обширной библиотеке табулатур (более 1 миллиона).
- Обеспечить точное отображение нот и аппликатур.
- Реализовать интерактивное воспроизведение MIDI с возможностью изменения темпа (замедление до 50%).
- Предоставить инструменты для отработки сложных пассажей (повтор выделенного фрагмента, Solo по инструменту).

## 2. Целевая аудитория
- **Начинающие гитаристы/басисты:** Которые ищут простой способ быстро найти табы и разобрать песню, используя визуализацию и замедление.
- **Продвинутые музыканты:** Кому нужны быстрые и точные табулатуры для разучивания соло или партий ударных.
- **Преподаватели музыки:** Использующие интерактивные табы для наглядного обучения.

## 3. Проблемы, которые решает приложение
1.  **Поиск качественных табов:** Пользователи тратят много времени на поиски корректных табулатур. Songsterr предлагает один выверенный вариант на песню, отсортированный по релевантности.
2.  **Неудобство чтения с листа:** Традиционные табы статичны. Songsterr решает проблему "как это должно звучать", проигрывая таб синхронно с подсветкой ноты.
3.  **Сложность разучивания быстрых партий:** Встроенный плеер позволяет замедлять музыку без искажения тона, что критично для обучения сложным риффам.
4.  **Правовые риски:** В отличие от "серых" сайтов с табами, Songsterr легален и платит авторам, решая проблему этичного потребления контента.

## 4. Аналоги и сравнение
| Критерий | **Songsterr** | Ultimate Guitar Pro | MuseScore |
| :--- | :--- | :--- | :--- |
| **Тип контента** | Интерактивные табы с ритм-нотацией | Табы (пользовательские и официальные) | Ноты и табы (партитуры) |
| **Интерактивность** | Высокая (плеер, регулировка темпа, изоляция) | Средняя (есть проигрывание) | Высокая (воспроизведение партитур) |
| **Модель оплаты** | Фримиум (есть реклама и платный PRO-доступ к функциям)  | Фримиум (основной контент платный) | Фримиум |
| **Качество табов** | Единая версия, в целом высокое качество | Сильный разброс качества, зависит от рейтинга | Официальные ноты (ноты, а не упрощенные табы) |
| **UI/UX** | Простой, минималистичный | Перегруженный, много рекламы | Классический нотный стан |

## 5. Описание работы приложения
- **Тип проекта:** Кроссплатформенное приложение.
- **Веб-версия:** Адаптивный сайт (HTML5/JS), работающий через браузер. Ранее требовал Flash.
- **Мобильная версия:** Нативные приложения для iOS и Android, доступные в магазинах приложений. Дата последнего обновления Android версии — Май 2026.
- **Основной функционал:** Поиск -> Выбор песни -> Интерактивный просмотр таба -> Управление плеером (Play/Pause, Loop, Speed Control) -> Настройка микса инструментов.
