# Чеклист тестирования веб-приложения Songsterr

**Проект:** Songsterr (интерактивные табулатуры)  
**Спринт:** 
**Ветка:** `Task2`  
**Авторы:** Зорин П.Л.

---

## Раздел 1. Главная страница (Поиск и навигация)

- [ ] **Отображение страницы**
  - [ ] Страница загружается менее чем за 3 секунды
  - [ ] Адаптивная верстка корректна (десктоп, планшет, мобильный)
  - [ ] Нет наложения элементов или "битых" зон
- [ ] **Поиск табов**
  - [ ] Поиск по названию песни возвращает результаты
  - [ ] Поиск по имени исполнителя возвращает результаты
  - [ ] Поиск по части слова (например, "Bohem" → "Bohemian Rhapsody") работает
  - [ ] Пустой поиск показывает подсказку или топ-табы
  - [ ] Неверный запрос выводит сообщение "Ничего не найдено"
- [ ] **Фильтры и сортировка**
  - [ ] Фильтр по инструменту (гитара, бас, ударные) работает
  - [ ] Сортировка по популярности/дате работает корректно
- [ ] **Навигация**
  - [ ] Клик по логотипу возвращает на главную
  - [ ] Ссылки в футере ведут на правильные страницы (About, Contact, Terms)

---

## Раздел 2. Страница табулатуры (Плеер и отображение)

- [ ] **Загрузка таба**
  - [ ] Таб открывается по клику из результатов поиска
  - [ ] Отображается название песни и исполнитель
  - [ ] Отображается выбранный инструмент (гитара, бас, ударные)
  - [ ] Нотная запись и табулатура отображаются без искажений
- [ ] **Управление плеером**
  - [ ] Кнопка Play запускает воспроизведение
  - [ ] Кнопка Pause останавливает воспроизведение
  - [ ] Перемотка кликом по временной шкале работает
  - [ ] Индикатор текущей позиции движется синхронно с музыкой
  - [ ] Подсветка текущей ноты/такта совпадает со звучанием
- [ ] **Регулировка темпа (Speed)**
  - [ ] Слайдер скорости работает (доступные значения в бесплатной версии)
  - [ ] Звук не искажается при замедлении
  - [ ] Значение скорости отображается корректно
- [ ] **Loop / Повтор фрагмента**
  - [ ] Установка начала и конца повтора работает (если доступно в бесплатной версии)
  - [ ] Зацикленный фрагмент повторяется корректно
  - [ ] Сброс повтора (Loop Off) работает
- [ ] **Зум и прокрутка**
  - [ ] Приближение / отдаление партитуры работает
  - [ ] Горизонтальная прокрутка для длинных табов работает

---

## Раздел 3. Страница профиля пользователя (Базовая функциональность)

> **Примечание:** Тестируется только бесплатный функционал. PRO-функции не проверяются.

- [ ] **Регистрация / Вход**
  - [ ] Регистрация через email работает
  - [ ] Вход через Google работает
  - [ ] Неверный пароль показывает ошибку
  - [ ] Восстановление пароля работает
- [ ] **Настройки пользователя**
  - [ ] Смена аватара работает
  - [ ] Настройка темной/светлой темы сохраняется после перезагрузки
  - [ ] Настройка инструмента по умолчанию (гитара/бас) сохраняется
- [ ] **Избранное / Закладки**
  - [ ] Добавление таба в избранное работает
  - [ ] Удаление из избранного работает
  - [ ] Страница "Мои табы" отображает добавленные песни

---

## Раздел 4. Мобильная версия (Адаптив и сенсорное управление)

> **Важно:** Тестируется на реальных iOS/Android устройствах или эмуляторах

- [ ] **Адаптивная верстка**
  - [ ] Все элементы читаемы без горизонтального скролла
  - [ ] Табулатура масштабируется под ширину экрана
- [ ] **Сенсорное управление плеером**
  - [ ] Перемотка касанием по шкале времени работает
  - [ ] Жест Pinch-to-zoom на табулатуре работает без сбоев
  - [ ] Свайп назад (back swipe) не конфликтует с плеером
- [ ] **Производительность на мобильных устройствах**
  - [ ] Воспроизведение MIDI не прерывается при фоновой работе других приложений
  - [ ] Скролл страницы плавный, не менее 60 FPS
  - [ ] Нет вылетов (crash) при быстром нажатии Loop + Speed

---

## Общие критерии приемки

- [ ] Нет критических багов (блокирующих основной сценарий)
- [ ] Все ссылки ведут на существующие страницы (нет 404)
- [ ] Консоль браузера не содержит JavaScript-ошибок
- [ ] Нагрузка на странице таба не превышает 150 МБ RAM
